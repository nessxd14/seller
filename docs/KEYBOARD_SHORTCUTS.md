# Atajos del POS ROARI

| Atajo | Acción |
|---|---|
| `F2` o `/` | Enfocar buscador |
| Escáner + `Enter` | Agregar coincidencia exacta por código, SKU, código de fábrica o nombre |
| `F8` | Suspender operación actual |
| `F9` | Abrir cobro |
| `Ctrl + N` | Nueva operación con confirmación cuando hay productos |
| `Escape` | Cerrar el modal activo |

Los atajos no omiten validaciones ni confirmaciones.
